# Compressy v1.0.2

This update rebuilds Compressy as a maintained standalone add-on with the complete vanilla-rooted UtilityCraft compression catalog.

## HIGHLIGHTS

- Added all current UtilityCraft compression chains rooted in vanilla blocks.
- Added 39 compressed storage items for common vanilla resources.
- Added reproducible content synchronization and validation tooling.
- Added automated development, minified, GitHub and CurseForge release support.

## ADDED

- Added every current UtilityCraft compression chain rooted in a vanilla Minecraft block.
- Added all 39 compressed storage items for common vanilla resources.
- Added a reproducible UtilityCraft synchronization tool and a standalone content audit.
- Added automated development and minified Regolith builds for GitHub Releases.
- Added automated CurseForge publishing for project 1387104.

## CHANGED

- Rebuilt Compressy as a maintained standalone Regolith project.
- Updated block definitions, recipes, textures, sounds, localizations, and creative inventory groups from UtilityCraft.
- Updated both packs to version 1.0.2 while preserving published UUIDs and content identifiers.

## FIXED

- Removed dependencies on UtilityCraft-only ores, metals, crushed materials, silicon, and other custom block families.
- Removed stale and orphaned compressed content that had no complete standalone recipe chain.

## COMPATIBILITY

- Requires Minecraft Bedrock 1.21.120 or newer.
- Requires no experiments, scripts, or other add-ons.
